# MiniMax 隔夜情绪 Gap 策略 · v0.1 (Paper Only)

**标的**: 稀宇科技 MINIMAX-WP (00100.HK) · Hyperliquid MINIMAX perp
**分类**: ⚠️ **方向性动量 (alpha 小仓)** + ✅ **perp–正股 basis 收敛 (真套利)** — 两个独立子策略
**状态**: v0.1 — 未通过四量验收前 **只允许 paper trade，禁止实盘**
**格式基准**: Type A 隔夜传导策略文档

---

## 0. 正名 (不可删除的前提)

"美股跌 → 开盘做空 MiniMax → 获利" **不是套利**。套利 = 两个锚定同一终值、报价不同的工具之间可锁定的价差，无论涨跌都收敛。此信号没有任何锁定价差，是纯方向 bet，赌"美股情绪传导到 MiniMax 开盘"。

**为什么必须正名**: 叫套利会按套利的信心加仓。方向性交易只能 alpha 小仓 + 硬止损。因此本文档拆成两个子策略：

| 子策略 | 性质 | 风险预算 |
|---|---|---|
| **M-DIR** 方向性动量 | 猜涨跌，赌情绪传导 | alpha 小仓，单笔 ≤ 3% 量化 AUM，paper 验收前为 0 |
| **M-BASIS** perp–正股 basis 收敛 | delta-neutral，可锁价差，真套利 | 验收后可用套利仓位框架 |

## 1. 标的画像与核心风险

- **身份**: 18C 特专科技 + 同股不同权 + 未商业化 ("P" 标记)。
- **Idiosyncratic 噪声怪兽**: 首轮天量解禁砸 ~18%（解禁前高盛/美银/花旗同步买入评级）；M2/M3 模型发布、WAIC 催化、回 A 传闻。52 周区间 220–1330，单日 ±12–18% 常态（前收 663.5 → 553 级别跳空）。
- **直接后果**: 隔夜美股 beta 贡献被解禁盘/评级/发布的方差淹没。Type A 最惨单笔 -6.3% 是 ADVANTEST 财报日事故——**MiniMax 现在是"天天财报日"**。它是全市场最不适合跑情绪传导信号的标的之一，因此黑名单是本策略第一道闸，且"干净信号日剩多少"本身就是 go/no-go 指标。

### 港股微观结构硬约束

1. **没有连续盘前**。09:00–09:20 HKT 是开市前集合竞价（09:00–09:15 可挂/改单，09:15–09:20 禁改，09:20 撮合出开盘价）。你只能往竞价里挂单，而 IEP 已把美股隔夜 gap 定价进去。
2. **"开盘前 5 分钟情绪最大" 直觉是反的**。情绪影响最大 ≠ edge 最大。edge 在"gap 未被定价但将被定价"时；竞价尾段恰是已定价程度最高的时刻。→ **已定价比例 < 50% 才做**（Type A 规则；KIOXIA/韩股跟随信号亏损的直接原因）。
3. **卖空 tick rule + 券源**。港股空单不得低于最佳卖价成交，gap-down 方向恰恰最难挂空；天量解禁后借券紧/贵/间歇不可空。→ 做空方向优先用 perp（绕开 tick rule 与券源），但 perp 24/7 交易，隔夜可能已定价 + funding 成本，**用正股还是 perp 决定 edge 在哪、还在不在**，由已定价比例逐日实测回答。

## 2. 信号模型 — 必测四量 (回测引擎实现)

| # | 量 | 定义 | v0.1 验收线 (go/no-go) |
|---|---|------|------------------------|
| Q1 | **传导比** | 干净日中 \|美股 AI 篮子隔夜收益\| ≥ 阈值时，MiniMax 开盘 gap（及开盘后 15/30 分钟收益）对篮子收益的回归 beta + 方向一致率。MiniMax 无 ADR，预测源用 KWEB/中概 AI + 纳指/费半篮子 | beta ≥ 0.3 且 t-stat ≥ 2.0；方向一致率 ≥ 60% |
| Q2 | **已定价比例** | 进场那一刻参考价（竞价 IEP 或 perp 现价）已反映的预期 gap 占比：`(ref/prev_close − 1) / (beta × basket_ret)` | 中位数 < 50%，且 ≥ 50% 的日子必须全部拒单 |
| Q3 | **衰减** | 开盘后 gap 多久回吐/反转，定持仓窗口。Type A 实测 +1h 开始回吐；MiniMax 波动更大，窗口可能只有几分钟到十几分钟 | +15m/+30m 累计收益仍同向且 > 成本；据此定硬平时刻 |
| Q4 | **黑名单占比** | 解禁、财报、投行评级密集、模型发布、指数调整日全拉黑后，剩余干净信号日数量 | 干净信号日 ≥ 30 天才有统计意义；若黑名单吃掉 >70% 交易日 → 换载体（恒生科技或 智谱+MiniMax+群核 篮子摊薄个股噪声） |

四量任一不达标 → M-DIR 直接 kill，不降标准继续。

## 5. M-BASIS — 名副其实的套利版本

盯的是 **Hyperliquid MINIMAX perp vs 00100.HK 正股** 两个价格锚同一终值：

- **窗口**: 港股收盘 (16:00 HKT) 后 perp 继续交易到次日开盘。若美股大跌把 perp 砸**过头**、偏离"开盘正股将回到的公允价"→ perp 空 / 正股多（或反向），赌**开盘收敛**，不赌方向。delta-neutral、可锁、perp 端做空无 tick rule。与 H2 "pre-IPO perp 跨所价差扫描" 同类结构性机会。
- **触发**: |basis| = |perp / 正股参考公允价 − 1| ≥ 1.5%（扣除全部成本后仍为正才触发）。成本项：perp taker 费 ×2 + 持仓期 funding + 港股印花税/佣金 + 竞价滑点预算。
- **执行**: 夜间 perp 腿先建（流动性实测），09:00–09:14 竞价挂正股对冲腿；09:20 开盘后按收敛平仓，10:00 未收敛也硬平（收敛失败 = 记录进回测，连续 3 次收敛失败暂停策略）。
- **前提实测**（`run_basis.py` 扫描器负责积累数据）: perp 深度与冲击成本、funding carry 正负、开盘两边是否真的收敛、有无 price band 限制对冲。

## 6. 风控总则

1. Paper 阶段：一切信号只记 JSONL，不碰真钱。四量验收通过才讨论实盘化。
2. 实盘化后：M-DIR 单笔 ≤ 3% 量化 AUM、日内最多 1 笔、周亏损 ≥ 2 笔止损日则整周停；M-BASIS 名义 ≤ 10% 量化 AUM 且两腿必须同日建齐，建不齐立即撤单平腿。
3. 黑名单缺失 = 事故。任何一次"事后发现当天有 catalyst 但没进黑名单"都要求补日历 + 当周停跑。
4. 本策略独立核算，归入量化二级业务，不计基金 NAV（与 dashboard 口径一致）。
